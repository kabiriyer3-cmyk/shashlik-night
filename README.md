# 🔥 Шашлычная ночь

Игра от первого лица в браузере: дача, закат, мангал и голодные друзья. Жарь шампуры (свинина, овощи, курица, люля), следи за жаром углей, туши вспышки, гоняй Шарика и корми всех до полуночи. Можно играть одному или вместе, до 4 поваров по сети.

**Все модели, текстуры, скелеты и анимации создаются кодом на Python** (`tools/`): готовых 3D-файлов в репозитории нет. Игра написана на three.js (`src/`), звук синтезируется прямо в браузере.

## ▶️ Играть

После первого деплоя: **https://kabiriyer3-cmyk.github.io/shashlik-night/**

Управление: `WASD` ходить, мышь смотреть, `ЛКМ` взять / положить / перевернуть / угостить, `E` снять с мангала, `F` раздуть угли, `Q` сбрызнуть вспышки, `1–4` фразы в кооперативе, `Esc` пауза и настройки.

## 🚀 Деплой на GitHub Pages (один раз)

1. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. **Actions → «Build & deploy to GitHub Pages» → Run workflow** (или просто запушь что-нибудь в `main`).
3. Через 2–3 минуты игра будет доступна по ссылке выше.

Workflow сам ставит Python и Node, генерирует модели, собирает один файл `dist/index.html` (около 3 МБ) и публикует его.

## 👥 Кооператив на GitHub Pages

GitHub Pages хостит только статику, поэтому игроки находят друг друга через бесплатный сервер **PeerJS**, а сама игра идёт напрямую между браузерами (WebRTC). Хозяин жмёт «Создать дачу» и отправляет друзьям код из 4 символов, а друзья открывают ту же ссылку и жмут «Войти».

Если друзья в разных сетях, связь идёт через общий бесплатный TURN от PeerJS. Если он медленный или не пробивается, подключи свой:
1. Возьми бесплатный TURN, например в Metered (metered.ca → TURN Server).
2. Скопируй `public/ice.example.json` в `public/ice.json` и впиши свои данные.
3. Запушь изменения. В меню внизу блока «Кооператив» появится «свой TURN из ice.json ✓».

⚠️ На GitHub Pages `ice.json` виден всем, поэтому используй отдельные ключи с лимитом. Спрятать ключи можно на Netlify (см. ниже).

## Netlify (по желанию)

Этот же репозиторий деплоится и на Netlify (`netlify.toml`): Import from Git, ничего не настраивая. Там включаются свои функции подбора игроков (`netlify/functions`), а ключи TURN хранятся в переменных окружения: `CF_TURN_KEY_ID` + `CF_TURN_API_TOKEN` (Cloudflare), `METERED_DOMAIN` + `METERED_API_KEY` (Metered) или `TURN_URLS` + `TURN_USERNAME` + `TURN_CREDENTIAL`.

## 🛠 Собрать локально

```bash
pip install -r requirements.txt
npm install
npm run build          # -> dist/index.html (можно открыть прямо из папки)
npm run build:fast     # без перегенерации моделей
```

## Структура

| Путь | Что там |
|---|---|
| `tools/` | генератор моделей на Python: меши, шумовые текстуры, скелеты, IK-анимации, экспорт GLB |
| `src/game/` | код игры, части одного модуля (склеиваются по порядку при сборке) |
| `src/net.js` | кооператив: WebRTC, PeerJS, Netlify-сигналинг, коды комнат |
| `src/audio.js` | синтезированный звук: шипение, угли, сверчки, гитара Димы, голоса |
| `src/template.html` | интерфейс и стили |
| `scripts/build.mjs` | сборка в один HTML-файл |
| `netlify/functions/` | (необязательно) свой сигналинг и выдача TURN для Netlify |
